4. 修改窗口类的 GCL_CBWNDEXTRA 会发生什么？

What happens if you change a window class’s GCL_CB­WND­EXTRA? — devblogs.microsoft.com/oldnewthing · 1 天前 · ⭐ 21/30

Windows 编程中修改窗口类的 GCL_CBWNDEXTRA 属性只会影响之后创建的新窗口，而不会改变已存在窗口的额外字节分配。系统在创建窗口时会根据当时的类定义分配内存，因此动态修改该值无法追溯调整旧窗口的内存布局。这种行为符合 Windows API 的一致性原则，即窗口实例的属性在创建时即已确定。开发者若需调整所有窗口的额外空间，必须销毁旧窗口并重新创建。

🏷️ Windows API, Win32, C++, OS internals

5. 计算矩阵秩的下界

Computing a lower bound on matrix rank — johndcook.com · 1 天前 · ⭐ 20/30

矩阵秩的计算在实际应用中面临非连续性、舍入误差和数据噪声三大挑战，使得精确判定线性无关性变得困难。文章引入了“稳定秩”（Stable Rank）的概念，定义为 Frobenius 范数的平方除以算子范数的平方。稳定秩作为秩的一个下界，对矩阵元素的微小扰动不敏感，提供了比传统秩更稳健的数值特征。通过这种方式，研究者可以在存在噪声的情况下更可靠地评估矩阵的性质。

8. 秩-迹定理的证明

文章详细推导了实对称矩阵的秩-迹不等式，即矩阵的秩不小于其迹的平方与平方迹之比。证明过程主要利用了矩阵的对角化性质，将秩表示为非零特征值的个数，将迹表示为特征值之和。通过应用柯西-施瓦茨不等式（Cauchy-Schwarz inequality），严谨地建立起矩阵秩与迹之间的定量关系。这一结论为前文提到的“稳定秩”提供了理论支撑，展示了代数性质与数值界限的内在联系。
