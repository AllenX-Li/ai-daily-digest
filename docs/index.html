💡 为什么值得读: 关注计算机科学理论的底层颠覆，了解这一发现如何重塑我们对算法复杂度和加密安全的认知。

14. 探究为何程序在批处理文件中运行失败，但在资源管理器中双击却正常

Puzzling out why a program doesn’t work when run from a batch file, but works when double-clicked from Explorer — devblogs.microsoft.com/oldnewthing · 1 天前 · ⭐ 23/30

批处理文件与资源管理器启动程序的行为差异常导致运行失败，核心问题在于当前工作目录（CWD）的设置不同。资源管理器启动程序时会自动将 CWD 设置为可执行文件所在的文件夹，而批处理文件默认继承调用它的 Shell 路径。这种差异会导致程序因找不到相对路径下的配置文件或依赖库而崩溃。作者建议在批处理脚本开头使用 `cd /d %~dp0` 命令，强制将工作目录切换至脚本所在位置以模拟资源管理器的环境。通过这种方式，可以确保程序在任何调用环境下都能正确加载其依赖项。
