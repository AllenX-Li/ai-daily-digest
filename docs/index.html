10. C++ 提醒：函数局部静态变量仅初始化一次

C++ reminder: Function-local static variables are initialized only once, even if it looks like they get initialized multiple times — devblogs.microsoft.com/oldnewthing · 22 小时前 · ⭐ 23/30

在 C++ 编程中，函数内部定义的静态变量（Function-local static variables）具有特殊的生命周期，它们仅在程序执行流首次经过定义处时进行初始化。即使该函数被多次调用，或者初始化代码看起来位于循环或频繁执行的路径中，初始化逻辑也只会运行一次。这种机制由编译器通过内部标志位（Guard variable）来保证线程安全的单次初始化。开发者需要警惕依赖多次初始化的逻辑错误，并理解其背后的线程同步开销。

🏷️ C++, static variables, initialization
