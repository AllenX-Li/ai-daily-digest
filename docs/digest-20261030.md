### 8. 避免公有函数互相调用

> 提出了一项关于 API 设计的小型经验法则：应避免让一个公有（Public）函数直接调用另一个公有函数。这种做法旨在减少 API 内部的耦合度，防止修改一个导出接口时意外影响到另一个接口的行为。虽然作者承认这只是一个经验法则且缺乏具体案例，但其核心逻辑在于保持公有接口作为独立入口点的纯粹性。通过将共享逻辑提取到私有辅助函数中，可以显著提升代码库的可重构性和接口的稳定性。
